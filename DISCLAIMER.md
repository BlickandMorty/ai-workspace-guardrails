# Security and legal disclaimer

This repository is a reference implementation, not a certification, compliance determination, managed security service, or substitute for legal and security review.

Test with disposable data first. Incorrect NTFS rules can make data inaccessible. Keep independently verified backups and a documented recovery account. Do not store secrets or personal data in the policy, logs, example files, or public issue reports.

The toolkit cannot distinguish a human from an AI process when both use the same Windows identity. It cannot stop a local administrator, kernel-level attacker, compromised service account, offline disk access, or an authorized identity that intentionally misuses access. Stronger environments should use separate identities, encryption, endpoint management, centralized logging, and network-side controls.

Do not use this toolkit to conceal unlawful activity, deny people access to their own legally required records, evade oversight, or bypass a platform's terms or security controls.
