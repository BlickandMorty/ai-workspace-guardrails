# Lineage

This project extends the Windows Resilience Suite's protected-path and integrity patterns into a vendor-neutral enterprise workspace boundary. It was added after the complete lockdown/performance inventory to address multi-project AI and data-work isolation.

Reused design ideas include dry-run-first execution, explicit acknowledgements, SYSTEM verification tasks, SHA-256 manifests, protected canonical policy copies, and accurate Windows identity boundaries. Machine-specific policies, live ACLs, customer data, platform names, secrets, and permanent-laptop enforcement artifacts are excluded.
